
# YouTube Recommendation System

## Project Description
This project recommends similar YouTube videos using a content-based recommendation system.

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- TF-IDF
- Cosine Similarity

## Features
- Select a video
- Recommend similar videos
- Interactive web application

## How to Run
1. Install required libraries:
   pip install -r requirements.txt

2. Run the application:
   streamlit run app.py
